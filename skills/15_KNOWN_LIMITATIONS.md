# 15 — Known Limitations

**Purpose:** Make missing knowledge visible so it is not mistaken for a design.

**Confidence note:** verified against the workspace contents on 2026-11-23. The code wins (see 16).

1. The product name, stack, users, and requirements remain placeholders.
2. `mint-api` and `mint-web` contain no implementation.
3. There is no database, API contract, CI, deployment configuration, test suite, or dependency manifest.
4. Authentication and privacy requirements are stated but have no verified controls.
5. No incident history or performance measurements are available.

These are ranked by their ability to invalidate later design work. Do not treat this document as
an accepted security or release waiver.
